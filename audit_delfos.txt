### 1.5 Candil ↔ Delfos
| Aspecto | Verdict |
|---------|---------|

| `Code.ensure_loaded?` es siempre true | ⚠️ Candil es dep compilado, el fallback directo es dead code |
| **Veredicto** | ⚠️ Integración funcional pero superficial. Sin tests, sin cobertura de errores. |

## 4. Bugs y Problemas Funcionales

### 4.1 `--fix` mode en doctor NO FUNCIONA 🔴
```elixir
# doctor.ex:51
defp run_pretty(_fix_mode, _interactive) do
```
El flag `--fix` se acepta pero **nunca se usa**. Antes lo manejaba `Botica.Repair.Fixer`. Ahora no hay implementación. El usuario cree que puede auto-reparar pero no hace nada.

### 4.2 `--db-only` y `--llm-only` no existen 🔴
El README los documenta pero doctor.ex solo acepta `--fix`, `--interactive`, `--json`.

### 4.3 `delfos setup` no está en la CLI table del README 🟡
Comando funcional pero no documentado.

### 4.4 `Candil.Application` no arranca `Candil.Registry` 🟡
Si alguien intentara usar motores locales de Candil desde Delfos, crashearía con `Registry.lookup/2` porque el proceso no existe.
